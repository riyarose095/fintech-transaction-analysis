# Fintech Transaction Analysis  

This project analyzes fintech transactions using **Databricks SQL** for data processing and **Power BI** for visualization.  
The goal was to explore transaction trends, customer behavior, and payment method preferences to generate actionable insights for fintech businesses.  

---

## 🔹 Project Workflow  
1. **Data Preparation** – Cleaned and transformed data using Databricks SQL.  
2. **Data Visualization** – Built an interactive Power BI dashboard with KPIs and charts.  
3. **Insights & Reporting** – Highlighted key metrics such as revenue trends, customer activity, and default rates.  

---

## 📊 Key Insights  
- 💰 **Total Transaction Value**: ₹23.2M over 2 years  
- 👥 **Unique Customers**: ~1,000 analyzed  
- 💳 **Top Payment Methods**: Credit Card & Wallet  
- 📈 **Trend**: Strong growth in digital wallet usage compared to traditional methods
